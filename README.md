# 🍎 Apple Inc. FP&A Financial Model

## 📊 Project Overview
A complete Financial Planning & Analysis (FP&A) model 
for Apple Inc. built using real Kaggle dataset 
covering 15 years of financial data (2009–2022).

## 🎯 What's Inside
- ✅ 15 years historical data analysis (2009–2022)
- ✅ 5-year revenue forecast (2023–2028) at 8% CAGR
- ✅ Gross margin analysis → 39.8% average
- ✅ Net profit margin → 22.5% average
- ✅ Variance analysis → 2023 missed forecast by -10%
- ✅ YoY growth analysis → peak +66% in 2014

- Financial Modeling
